# ocsge-pv : traitement multisources de données OSCGE sur le parc photovoltaïque français
Les outils de cette suite servent à traiter, pour les besoins du produit OCSGE de l'[IGN](https://www.ign.fr), des données décrivant les installations photovoltaïques en France.

Les outils comme la base de données peuvent être déployés et utilisés dans différentes configuration.
